## 3. СПЕЦИФИКАЦИЯ ЭНДПОИНТОВ БОТА (`app/gateway/`)

Для обеспечения контракта [docs/phase3-integration.md](file:///c:/Users/Z0KA0/Desktop/work/site1/docs/phase3-integration.md), в шлюз бота (`app/gateway/`) добавляются 3 обработчика:

### 3.1. `POST /api/internal/order-paid` — Доставка заказа в чат
* **Защита:** Заголовок `X-Internal-Secret` равен `settings.internal_secret`.
* **Входные данные (JSON):**
```json
{
  "telegramId": "1304771090",
  "orderNo": 482913,
  "orderSecret": "031337",
  "productSlug": "chatgpt-pro",
  "productTitle": "ChatGPT Pro",
  "kind": "account",
  "totalCents": 399000,
  "network": "TRC-20",
  "asset": "USDT",
  "amountCrypto": "43.37",
  "txHash": "a4f89d53c7...",
  "credentials": "LOGIN = livka.test@gmail.com\nPASSWORD = SecretPass123",
  "paidAt": "2026-09-24T10:00:00.000Z"
}
```
* **Поведение бота:**
  1. Бот формирует премиальное HTML-сообщение пользователю в Telegram:
     ```html
     🎉 <b>Заказ #{orderNo} успешно оплачен и выдан!</b>

     📦 <b>Товар:</b> {productTitle}
     💵 <b>Сумма:</b> {amountCrypto} {asset} ({network})
     🔗 <b>TxID:</b> <a href="https://tronscan.org/#/transaction/{txHash}">Проверить в блокчейне</a>

     🔑 <b>Ваши данные доступа:</b>
     <pre><code>{credentials}</code></pre>

     <i>Нажмите на блок выше, чтобы скопировать данные. Данные также сохранены в вашем профиле на сайте livkamarket.app.</i>
     ```
  2. Дублирует уведомление в закрытый админ-чат (`ADMIN_CHAT_ID`):
     `💰 Оплачен заказ #482913 на сумму 43.37 USDT от пользователя 1304771090`.
* **Ответ:** `{"ok": true, "delivered": true}`

---

### 3.2. `GET /api/internal/users/{telegramId}/profile` — Профиль для Mini App
* **Защита:** Заголовок `X-Internal-Secret` равен `settings.internal_secret`.
* **Назначение:** Позволяет Mini App на сайте моментально показать статус триала.
* **Логика:**
  Загружает пользователя по `telegramId` из таблицы `users` и связанный ключ из `api_keys`.
* **Выходные данные (JSON):**
```json
{
  "ip_verified": true,
  "trial_active": true,
  "trial_key": "livka-trial-ab12...cd34",
  "tokens_used": 14200,
  "tokens_limit": 1000000,
  "referrals_confirmed": 3,
  "referrals_required": 5
}
```
* Если пользователь не найден: `404 Not Found`.

---

### 3.3. `POST /api/auth/telegram/validate` — Валидация подписи Telegram
* **Назначение:** Используется сайтом для проверки данных Telegram Login Widget.
* **Входные данные (JSON):**
```json
{
  "type": "login_widget",
  "payload": {
    "id": "1304771090",
    "first_name": "Misha",
    "username": "BlockLoader",
    "auth_date": "1727170000",
    "hash": "abcdef123456..."
  }
}
```
* **Логика проверки:**
  - `secret_key = SHA256(bot_token)`
  - Сортировка полей и сборка `k=v\n`
  - `HMAC-SHA256(data, secret_key)`
  - Сверка с `hash` в постоянное время (`hmac.compare_digest`).
* **Ответ:** `{"valid": true}` (HTTP 200) или `{"valid": false}` (HTTP 401).

## 4. ДОРАБОТКА РОУТЕРА БОТА: КОМАНДА `/claim <secret>`

В бота добавляется файл `app/bot/routers/orders.py`:
* **Команда:** `/claim <6-значный секрет>` (например, `/claim 031337`).
* **Логика работы:**
  1. Бот берет `telegram_id = message.from_user.id` и введенный секрет.
  2. Отправляет запрос на сайт:
     `POST http://site:3000/api/internal/orders/claim`
     с заголовком `X-Internal-Secret`.
  3. Сайт находит анонимный заказ, связывает его с `telegram_id` и возвращает купленные данные доступа.
  4. Бот присылает пользователю карточку с реквизитами заказа:
     *«✅ Заказ #482913 успешно привязан к вашему аккаунту!»*.

## 6. ДЕПЛОЙ НА VPS (`livkamarket.app`)

1. **Применение SQL миграции на сервере:**
   ```bash
   docker compose exec -T db psql -U livka -d livkamarket < scripts/migrate-phase3.sql
   ```
2. **Сборка и запуск контейнера сайта:**
   ```bash
   docker compose up -d --build site
   ```
3. **Обновление Caddy:**
   В `deploy/Caddyfile` подключается `livkamarket.app -> reverse_proxy site:3000`.
   Перезапуск Caddy: `docker compose restart caddy`.
